# ASCII 动画导入说明

把动画文件放进**本文件夹**（与 `MiniTools.exe` / 项目根目录同级），应用**启动时**自动加载；也可以随时点击托盘菜单 **Reload Animations** 重扫并立刻切换展示（倒计时/庆祝场景不会被误打断）。

## 支持的文件格式

| 扩展名 | 解析方式 |
|--------|----------|
| `.json` | 结构化 JSON（推荐，字段明确） |
| `.txt` / `.ascii` | 纯文本：`# 键: 值` 元数据 + `===` 帧分隔线 |

- 文件名以 `_` 或 `.` 开头的文件会被**跳过**（可用来放未完成的草稿）。
- 其他扩展名一律忽略。

## 快速上手

### 方式一：JSON（推荐）

新建 `my_pet.json`：

```json
{
  "name": "my_pet",
  "color": "#000000",
  "fps": 3,
  "rainbow": false,
  "idle": true,
  "frames": [
    [
      "   /\\_/\\   ",
      "  ( o o )  ",
      "   \\_^_/   "
    ],
    [
      "   /\\_/\\   ",
      "  ( - - )  ",
      "   \\_^_/   "
    ]
  ]
}
```

字段说明：

| 字段 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `name` | 否 | 文件名 | 场景名；与内置场景同名时会覆盖内置 |
| `color` | 否 | `#000000` | 单色风格主色（十六进制） |
| `fps` | 否 | `2` | 播放帧率（帧/秒），最小为 1 |
| `rainbow` | 否 | `false` | 为 `true` 时逐行渐变着色 |
| `idle` | 否 | `true` | 为 `false` 时不加入待机轮换（仍可被指定为自定义场景） |
| `frames` | 是 | - | 帧数组；每帧是字符串数组，单帧动画可直接给字符串 |

### 方式二：纯文本

新建 `my_pet.txt`：

```
# name: my_pet
# color: #FF0000
# fps: 4
# rainbow: false
# idle: false
===
   /\_/\
  ( o o )
   \_^_/
===
   /\_/\
  ( - - )
   \_^_/
```

规则：

- 元数据行以 `# 键: 值` 写在**第一帧之前**；`name` 缺省用文件名。
- 帧之间用单独一行 `===`（或 `---`）分隔；没有分隔线时整个文件视为单帧。
- 键名大小写不敏感（`# Name: xx`、`# NAME: xx` 均可）。
- 布尔值可写 `true/false`，也接受 `1/0/yes/no/on/off`。
- 支持 `color` / `fps` / `rainbow` / `idle`，含义与 JSON 字段一致。
- 帧内容按行原样保留（含行首/行尾空格）。

## 加载与验证

- **启动时**自动扫描本文件夹；托盘菜单 **Reload Animations** 随时重扫并立即切换展示。
- 所有加载/失败记录都写入 `logs/app.log`：
  - 成功：`External ascii scene loaded: <场景名> <- <文件名>`
  - 失败：`External ascii scene load failed: <文件名>: <原因>`

## 常见问题

| 现象 | 原因 / 解决 |
|------|-------------|
| 导入后没出现 | 检查扩展名是否受支持、文件名是否以 `_`/`.` 开头；查看 `logs/app.log` 是否有 load failed |
| 与内置场景同名 | 以外部文件为准（覆盖内置） |
| 不想让它参与待机轮换 | 文本格式加 `# idle: false`；JSON 加 `"idle": false` |
| 播放时文字跳动 | 各帧行数/宽度不一致导致，请对齐（应用会自动补齐到最大宽高） |
| 画面被截断 | 建议单帧 ≤ 10 行、≤ 24 列，超出会在宠物窗口内被截断 |
| 帧内容是 `#` 开头的行 | 只要它出现在第一个 `===` 之后就会按帧内容处理，不会被当成元数据 |
